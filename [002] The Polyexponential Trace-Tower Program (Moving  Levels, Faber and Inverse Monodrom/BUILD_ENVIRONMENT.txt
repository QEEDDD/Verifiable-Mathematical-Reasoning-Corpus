POLYEXPONENTIAL TRACE-TOWER PROGRAM v3.1
REFERENCE BUILD ENVIRONMENT
========================================

The PDF and all exact certificates can be reproduced offline.  Network
access is neither used nor required after the following tools are installed.

PDF BUILD REQUIREMENTS
----------------------

The ordinary build invokes pdfLaTeX through latexmk.  main.tex uses these
LaTeX packages:

  geometry, fontenc, inputenc, lmodern, microtype,
  amsmath, amssymb, amsthm, mathtools, mathrsfs,
  booktabs, longtable, tabularx, array, multirow,
  enumitem, xcolor, fancyhdr, titlesec, tcolorbox,
  url, seqsplit, graphicx, float, hyperref, bookmark, cleveref.

A reasonably complete TeX Live installation supplies them.  The exact build
command is:

  latexmk -pdf -interaction=nonstopmode -halt-on-error -file-line-error -outdir=build main.tex

COMPUTATIONAL-CERTIFICATE REQUIREMENTS
--------------------------------------

* Python 3.10 or later (the frozen run used Python 3.12.13).
* SymPy (the frozen run used 1.14.0).
* NumPy, needed only by computation/trace_galois_401.py (the frozen run used
  2.3.5).
* A C++17 compiler, needed only by
  computation/even_derivative_separability_audit.cpp.
* POSIX shell utilities used by the Makefile: mkdir, tee, grep, awk, diff,
  rm, and sha256sum.

The programs use exact rational, integer, or finite-field arithmetic.  BLAS,
GPU, SageMath, Mathematica, and a network service are not required.

PROVENANCE-ONLY TOOL
--------------------

Pandoc is not needed to build the monograph or rerun any certificate.
tools/prepare_sources.py records a one-time historical ingestion step.  It
expects predecessor paths outside the standalone release and can overwrite
the reviewed modules with raw conversions.  Do not run it for an ordinary
or release build.  The frozen files in parts/ are the authoritative sources.

PORTABILITY NOTE
----------------

The version list above records the environment used for the release; it is
not a claim that every dependency must match byte-for-byte.  For the closest
reproduction, use the listed versions, verify CHECKSUMS.sha256, and compare
the stable extended-check summaries against the captured files in
computation/.  PDF metadata or compression may vary between TeX releases
even when mathematical content and pagination agree.
